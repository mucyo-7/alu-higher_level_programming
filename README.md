# alu-higher_level_programming

Exercises and projects for the Higher Level Programming curriculum.

## Requirements

- Editors: `vi`, `vim`, `emacs`
- Node.js version 14.x on Ubuntu 20.04 LTS
- Files end with a new line
- JavaScript files start with `#!/usr/bin/node`
- All files are executable
- Code follows `semistandard` style

## Directories

- `javascript-warm_up` — JavaScript basics: variables, constants, `console.log`
